## 📖 About
ChargeEase 2.0 is a full-stack EV Charging Station Finder and Slot Booking web app. It helps EV users find real charging stations, check slot availability, calculate charging costs, and book slots.

## ✨ Features

### Core Features
- 🔐 User Authentication (Register/Login/Logout)
- 📍 Real Station Discovery via Open Charge Map API
- 🗺️ Interactive Map with Turn-by-Turn Directions
- 📊 Live Slot Availability & Booking System
- ⭐ Ratings & Reviews
- 🔔 Notifications (In-app + Email)

### Advanced Features
- 🧠 Smart Recommendation Engine
- 💰 Charging Cost Estimator
- 📏 EV Range Calculator
- ⭐ Favorite Stations
- 📊 DSA Benchmarking (Linear Search & Selection Sort)
- 🛠️ Admin Dashboard

### Technical Highlights
- Flask + MongoDB Backend
- C DSA Integration (Linear Search, Selection Sort, Queue)
- Real-time data from Open Charge Map API
- Premium UI/UX with Glassmorphism
- Responsive Design

## 🛠️ Tech Stack
- **Backend:** Python Flask
- **Database:** MongoDB
- **Frontend:** HTML/CSS/JavaScript (Jinja2)
- **DSA:** C Programs (Linear Search, Selection Sort)
- **Maps:** Leaflet.js + OSRM
- **Charts:** Chart.js
